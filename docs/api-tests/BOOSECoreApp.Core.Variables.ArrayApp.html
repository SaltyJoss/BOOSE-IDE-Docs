The number of columns in the array

The number of rows in the array

Remarks

This constructor initializes a two-dimensional array based on the specified elementType. If elementType is Int, an integer array is created. If elementType is Real, a double-precision floating-point array is created. Unsupported element types will result in an exception.

Exceptions

ArgumentException

Thrown if elementType is not supported or if cols or rows are less than or equal to zero.
