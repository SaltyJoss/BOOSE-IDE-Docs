LogFATAL(string)

Logs a fatal error message to the debug output box in crimson, indicating critical failure.

public void LogFATAL(string msg)

Parameters

msg string

The message to log.

Remarks

This handler is used differently to error and warning logs as it indicates a critical failure that may require immediate attention. It may not be seen during normal operation as it indicates a severe issue. Therefore this handler is a distinct log level, that is here for the sake of completeness. Check debug logs for fatal errors during troubleshooting.
