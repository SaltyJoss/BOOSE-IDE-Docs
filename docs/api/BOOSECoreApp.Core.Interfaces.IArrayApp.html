Interface for array variable applications, defining the contract for array operations and properties.

public interface IArrayApp

Remarks

This interface is intended to be implemented by classes that manage array variables within the BOOSE IDE, providing methods and properties for array manipulation and access. Details of the array operations (e.g., getting/setting values, dimensions) are defined in the implementing classes.
