Remarks

ParserApp class tokenises and validates BOOSE commands ("Source Code") before execution. It fully supports multi-line programs, command assignments, variable assingments. It also handles both parsing AND exception handling.

Lines beginning with * are treated as a comment, and therefore are ignored. Empty Lines are skipped entirely.
